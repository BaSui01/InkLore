# 项目协作

[AGENTS](../AGENTS.md) 定义工程边界，[当前架构](architecture.md) 记录真实实现，[开发指南](development-guide.md) 说明验证方式。

任务目标、依赖、验收和状态统一放在 [GitHub Issues](https://github.com/BaSui01/InkLore/issues) / [Milestones](https://github.com/BaSui01/InkLore/milestones)，PR 关联已有任务。
不强制另分配 INK 编号，不在文档或 Wiki 复制进度。

Milestone 使用作者可观察的结果命名，不能固定领域数量、冻结版本或永久实施顺序。现有里程碑的调整按用户批准范围执行。

研究、临时方案和历史过程放入 [.agents/notes](../.agents/notes/README.md)。长期技术选择说明原因和影响，局部改动不必走独立 ADR 流程。
旧记录可以被新证据替代，但不能冒充当前验收。

交付说明包含问题、变更、实际验证和未解决风险；完成对应行为验收后才关闭任务。
