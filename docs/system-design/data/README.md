# 数据定义与迁移

本目录 SQL 是领域聚合结构资料；实际迁移由 [migrations/r1](../../../migrations/r1/) 内的有序版本和迁移器执行。
历史目录名承担已有迁移流身份，继续保留。

- 已应用迁移不改版本、内容或校验和。结构变更追加迁移，并核对旧数据和应用版本兼容性。
- 聚合 DDL 不应逐字等于最初迁移，也不能证明真实数据库已处于该结构。
- tenant / owner、复合外键、CAS、事实账本只追加、事务、重放与权限拒绝需要隔离数据库中的证据。
- 旧库导入需要可信映射与独立验证，不能按历史方案直接操作生产数据。
- [语义检查](../tools/check-design.cjs) 仅检查表归属和引用，不能替代迁移与查询验收。
