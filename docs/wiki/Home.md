# InkLore · 墨境 Wiki

InkLore 是 Go + React + PostgreSQL 的模块化单体 AI 小说创作平台，包含 Creator Studio、Admin Console、后台 API / Worker。

> 此 Wiki 是阅读与协作导航，不是第二份架构规范。正式设计、实际实现与任务状态，分别以仓库的 system-design、architecture 与 backlog 为准。项目仍处于持续重构阶段。
