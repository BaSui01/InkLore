# ADR-0037：源码文件大小上限调整为 500KiB

- **状态**：Accepted
- **日期**：2026-11-01
- **决策者**：项目用户明确指令
- **关联任务**：INK-251
- **替代关系**：仅替代 ADR-0001、ADR-0014 中源码单文件 50KB 条款；其他条款不变。保留 ADR-0036 生成输出布局。

## 背景（Context）

原 archguard 以 50 × 1024 字节扫描既有源码扩展，报告一个手写页面和16个生成契约超限。用户明确要求“最大文件限制到500k”，不采用生成契约分片方案。当前最大生成源码157276字节。

## 决策（Decision）

保持既有二进制计量方式，上限变为500 × 1024 = 512000字节，等于上限允许，超过拒绝。作用于archguard既有扫描源码扩展（含生成源码），不扩大忽略范围，不删除检查；跨域依赖、platform边界、禁测试源码、Go解析等规则不变。手写模块仍按职责合理拆分，大小允许不等于结构合理。

本次不改变设计文档、Skills、notes自身Markdown长度门禁，不改冻结资产/manifest/API/DDL、生成器或生成契约内容。既有Accepted ADR和历史验收记录原样保留，由此ADR明确替代相关源码阈值条款。

## 备选方案（Alternatives）

- 继续50KiB并对生成契约分片：用户选择500KiB，此方案不实施。
- 完全取消大小限制或忽略生成代码：超出用户限定500k，不采用。

## 后果（Consequences）

现有17个大小违规在新阈值下可通过；这是用户明确规则变更，不是证明旧50KiB已满足。PR9手写组件拆分保留可独立审查，不因阈值调整回滚。完整业务和独立验收仍分别保留。
