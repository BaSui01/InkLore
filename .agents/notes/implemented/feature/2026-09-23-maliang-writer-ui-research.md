### 一、系统全貌与视觉设计语言（Design System）

#### 1. 视觉风格：Dark Tech-Literary（沉浸黑金/黑曜石风格）
- **色彩层阶**：
  - **Base 底色**：`#0b0d10`（Obsidian Dark 极夜黑，消除长篇高强度码字疲劳）；
  - **Card / Panel 表面色**：`#16191f` 与 `#1e232d`，搭配 `1px solid rgba(255,255,255,0.08)` 细描边；
  - **核心强调色**：
    - 主操作：`#0ea5e9` ~ `#38bdf8`（亮天蓝胶囊），如【+ 创建小说】、【生成 1 版】；
    - 品牌与文学：`#f59e0b`（琥珀暖金）；
    - 状态徽章：青蓝 `#06b6d4`、翠绿 `#10b981`、亮红 `#ef4444`。

#### 2. 10 套网文专属主题配色（外观设置实测）
系统内置 10 种精调配色主题方案：
1. `默认（书香）`：温暖的书香色调，适合长时间阅读和写作（默认选中）；
2. `Highlighten（鲜亮）`：现代鲜亮的配色，充满活力和创意；
3. `Zen Garden（禅意）`：优雅的青绿色调，营造宁静禅意的写作氛围；
4. `Quadratic（几何白灰）`：纯净白灰画布与深墨文字，减少色彩干扰；
5. `Nomad（游牧者）`：充满活力的粉红与橙调主题；
6. `单色黑白`：简约的黑白极简配色；
7. `纸张风格`：复古的纸张微质感底纹；
8. `墨稿纸`：未漂白纸张与墨石青，给卡片一套安静的品牌层级；
9. `薰衣草之梦`；
10. `咖啡时光`。

#### 1. 系统设置组件体系（Settings Modal）
点击顶栏右侧设置图标呼出全屏模态窗口：
- **左侧导航栏**：
  1. ` 账户设置`：昵称、邮箱、密码；
  2. ` 积分记录`：Token 使用明细与充值账单；
  3. ` 写作周报`：日更字数曲线、连续天数、创作峰值时段；
  4. ` 外观设置`：深浅模式切换、10 套网文主题选择；
  5. ` 编辑器设置`（核心参数）：
     - **字体**：字号（滑块 12~32px）、衬线/非衬线字体下拉、字重（400/500/600）、行间距（1.5x~2.5x）、字符间距；
     - **布局**：水平边距（48px）、垂直边距（32px）、段落间距（24px）、首行缩进（16px）、最大行宽（2000px）；
     - **行为**：自动保存开关与间隔（1~10分钟）、**自动写作诊断 Beta 开关**（开启后在 Agent 生成前后自动扫描规则）、拼写检查、字数与行号显示；
     - **实时预览区**：底部配备两段示例文本实时展示参数调节结果；
  6. ` 写作模式`：多章编辑、单章切换、全景沉浸、极简打字机模式；
  7. ` 通知设置`、` 隐私设置`、` 关于`。

#### 2. 小说架构工作区（Novel Architecture Workspace）
点击顶栏【小说架构】按钮，中间区域切换为作品宏观架构设计中枢，包含三大 Tab：
1. **`基本信息`**：
   - **封面**：本地文件上传与 `[AI 生成封面]`；
   - **标题与状态**：草稿 / 进行中 / 已完成 / 已发布 / 已归档；
   - **类型与流派**：详细类型（爽文、种田文等）+ 类型标签池；
   - **主题与特色标签**：核心主题 + 特色标签（如系统、反派、无敌）；
   - **规格规划**：规划总章节数、规划每章字数；
   - **8 大主流平台渠道适配**：
     - `番茄小说`（男频爽文、快节奏、系统流、黄金三章、强爽点）；
     - `起点中文网`（世界观厚重、设定硬核、长线布局）；
     - `飞卢小说网`（脑洞炸裂、开局无敌、超长书名）；
     - `七猫免费小说`（都市生活流、情感细腻、强代入感）；
     - `晋江文学城`（女频、情感线细腻、文笔与群像）；
     - `息壤中文网`、`知乎盐选`、`短剧平台`（强冲突、密集反转、单元爆点）。
2. **`核心架构`**：
   - **核心种子 (Core Seed)**：核心创意、核心金手指、主要驱动矛盾；
   - **角色动力学 (Character Dynamics)**：角色性格、欲望动机、人物弧光与冲突网络；
   - **世界观 (World Building)**：世界运行法则、力量等级划分体系；
   - **情节架构 (Plot Architecture)**：宏观主线与大高潮节拍。
3. **`全局大纲`**：
   - 完整宏观剧情梗概，支持阅读模式与编辑模式自由切换。

#### 3. 右侧 Agent 协作与前端动态流式渲染（核心实测）
在主写作界面右侧展开的 Agent 抽屉中，我们实测获取了完整的通信与渲染链路：

##### (1) SSE 流式通信协议
- **端点**：`POST /api/v1/agent/supervisor/v4/stream`
- **信封格式**：`text/event-stream`，服务端分发结构化 JSON 事件：
  - `context_collection` → 前端渲染为带有旋转动画的 `⟳ 正在搜集小说上下文`；
  - `thinking_delta` → 前端流式填充到 `ThinkingBlock`（带折叠箭头的思考链卡片）；
  - `task_list` → 前端动态解析为 `TaskCard` 组件（任务标题、状态、所属 Agent 徽章）；
  - `ask_question` → 前端动态生成**内嵌交互式表单卡片**！

##### (2) 内嵌交互式问答表单（Interactive Ask Question Card）
当 Agent 发现当前小说缺少核心前提时，不会粗暴停止，而是**直接在聊天流中下发多步骤问答表单**：
- **卡片头部**：`小说架构方向确认（决定全书根基） 问题 1 / 4`；
- **选项题目**：
  - ① 核心题材与世界观底色（单选框组，包含灵气复苏、反套路修仙、无限流等）；
  - ② 发布渠道（多选，番茄/起点/飞卢等）；
  - ③ 主角与金手指倾向（废柴逆袭、开局无敌、智谋流、系统任务流等）；
  - ④ 氛围与核心卖点（神秘智慧配角、热血燃向、轻松幽默等）；
- **底部状态控制**：`●○○○ 已回答 0 / 4` 进度条、`[按意见重新生成]`、`[提交答案]` 主按钮。

##### (3) 7 大专业 Agent 动态调度与切换
点击【配置智能体】支持勾选当前会话启用的 Agent：
- `[√] 架构 Agent`（Structure）：推演核心种子与情节走向；
- `[√] 章纲 Agent`（Blueprint）：编排三级大纲与场景 Scene / 节拍 Beat；
- `[√] 设定 Agent`（Setting）：构建力量体系、角色与势力物品；
- `[√] 生成 Agent`（Generation）：产出正文；
- `[ ] 矫正 Agent`（Correction）：去 AI 味与文字润色；
- `[ ] 审查 Agent`（Review）：一致性防吃书检查（`consistency/guard`）。

#### 2. 后端核心接口支持（Go Backend）
- `POST /v1/agents/supervisor/stream`：输出带 `thinking`、`task`、`ask_question`、`artifact` 的 SSE 多通道事件流；
- `GET /v1/worldview/novels/{id}/consistency/guard`：一致性检查卫士接口，防止长篇吃书；
- `POST /v1/llm/budget/estimate`：实时 Token 与费用预估接口。
