# 01 · R1功能范围与验收追踪

状态：冻结设计，未实现。唯一全局契约见[00](00-CONTRACT-BASELINE.md)。R1按完整闭环交付，分阶段开发不意味着可以删去范围内功能。界面、API、数据和执行必须一致；不允许演示模板替代业务结果。

## 1. 产品与角色

面向私有部署的单人作者及小型创作团队；支持多租户隔离，同作品一次由拥有者编辑，不做多人实时协同。creator写作与运行自己的任务；operator管理本租户用户、模型、预算和工具；auditor只读脱敏审计。管理员不能以角色默认阅读小说正文。没有跨应用切换按钮，允许按ADR-0021注册独立creator租户；没有订阅支付或外部投稿。

作者闭环：创建作品→卷章大纲→设定资料→编写或AI候选→对比采纳→自动保存→版本审阅→事实确认→质检风险审阅→导出。模型运行成功只产生建议，正文保存与事实确认由作者明确动作触发。

## 3. 非功能基线

- 容量样本：10租户、100作品、每作品1000章×3000码点，API同时50读/10写；4核8GiB应用+4核16GiB PG、本机房1Gbps、已建索引、模型上游另测。非生成读取P95≤500ms、正文保存P95≤800ms，错误率<0.1%，测10分钟排除冷启动但不排除GC。达不到先记录瓶颈，不能缩小样本冒充通过。
- 生成首次增量由上游决定；网关收到增量后至客户端发送P95≤200ms，前端批渲染≤50ms一帧。10万码点编辑键入P95≤100ms，流过程中不全树重渲染。
- 保存返回成功必须代表PG已提交；刷新后可读取。不存在“已经在客户端看见即已持久化”的承诺。文件下载需hash校验；作业至少一次调度、业务副作用幂等，禁止称通用外部调用exactly-once。
- 安全：任何资源查/写先tenant+owner授权；跨scope与不存在同404；日志不含正文/凭据；请求/文件限制两端一致。两租户同资源名、同幂等键互不干扰。
- 无障碍目标WCAG2.2 AA交互要求，不宣称认证；对比度、焦点、键盘、读屏与减少动画逐项人工验证。双语zh-CN/en-US，日期与统计均北京时区。

## 4. 明确排除

R1不实现实时多人CRDT、SSO、支付、TTS、图片模型、外部站点自动抓取、自动发布到小说平台、跨租户全文查询。上传资料由用户提供，不默认有网页爬虫。历史文档中出现这些内容不构成R1要求；以后作为R2新增需求，不允许在R1放无法使用的入口。

## 5. “完成”的定义

每项FR均有：契约请求/响应、所属SQL与约束、应用服务/Port、权限、异常code、界面状态和可复现验收。设计冻结检查仅证明上述资产一致；功能完成还须真实PG、受控模型故障与浏览器证据，详见18。源码中已有类似函数可复用，但必须按R1行为重新验收，不以旧任务done抵扣。
