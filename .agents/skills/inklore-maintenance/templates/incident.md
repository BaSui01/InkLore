# INK-XXX 故障复盘模板

模板不是故障事实；仅填写已观察或能说明依据的内容，未知项明确标记未知。

## 影响与触发

环境 / 版本 / 时间范围 / 受影响对象（脱敏）/ 复现步骤 / 实际与预期。

## 证据与根因

请求标识、代码入口、最小日志、配置消费链、数据或状态变化。区分直接原因、促成因素、尚未证实的假设。

## 修复与取舍

采取的修复；真正比较过的其他方案及未采用原因；相关 ADR；是否改变接口、存储和运行路径。

## 验证与恢复

原故障重放、正常路径、失败路径、命令与退出码；发布或回滚实际执行情况；未执行项及原因。

## 工程笔记

根因与非显然修复采用 decisions 技能的已实施 note 模板，归类 bug-fix；将此复盘作为 Verification 证据链接，不把临时日志整段复制入笔记。

## 防复发与交接

新增护栏或操作检查、相关文档更新、剩余风险对应的 backlog 任务；不得另建平行任务状态表。
