# 故障复盘模板

仅填写已观察或有证据支持的内容；未知项保持未知，模板不代表事故已解决。

## 影响与触发

GitHub Issue/PR、环境、版本、时间范围、受影响对象（脱敏）、复现步骤以及预期与实际结果。

## 证据与根因

关联请求标识、调用链、最小日志、配置消费者和持久化状态；区分确定根因与仍待验证的假设。

## 修复与取舍

说明最小修复、真正比较过的方案及成本；重要长期决策按需留记录，不为局部修改强制补 ADR。

## 验证与恢复

原故障重放、正常路径和相关失败/权限边界；实际命令、退出码及证据。部署、回滚或恢复是否执行分别写清，未执行项注明原因。

## 交接

需要长期保留的根因与兼容理由写入对应工程笔记；其余讨论留在 GitHub。后续任务引用真实 Issue，不另建平行状态表。
