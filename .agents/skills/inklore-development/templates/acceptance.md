# 验收记录模板

模板不是已完成证据。小任务直接在 PR 中填写必要信息；只有证据较长或需长期追溯时才另存记录。

- GitHub Issue/PR 或当前用户任务：
- 日期、时区、环境与代码 SHA：
- 问题、根因和改动范围：
- 实际依赖及本次授权边界：

## 验证证据

| 场景/条件 | 命令或操作 | 预期 | 实际与退出码 | 脱敏证据 |
| --- | --- | --- | --- | --- |

## 行为与运行影响

说明受影响的入口、调用方、数据或配置消费者；如果只改文档或工具，准确说明相应范围。

## 文档与理由

只列本次实际更新的长期文档或工程笔记及原因，不要求每次同步所有文档。重要取舍链接证据，普通机械修改无需额外 note 或 ADR。

## 限制与交接

逐项说明未验证的行为、缺少的条件、已存在的错误与后续关联任务；任务状态只在 GitHub 维护。提交、合并、部署和数据操作的实际执行情况分别记录。
